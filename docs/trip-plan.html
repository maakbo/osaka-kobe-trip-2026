旅の詳細

大阪の味、USJの一日、有馬と神戸の時間を、家族3人で楽しむための案内。

大阪と神戸の味、景色、人と過ごす時間を、家族3人でゆっくり楽しむ。

予定を土台に、実際に起きた項目だけをその場で記録へ上書きしていく。

道頓堀の串カツ

店魅力・注意点当日の扱い
串カツ しろたや 道頓堀本店 なんば・日本橋から徒歩約5分。軽い衣の串カツを座って楽しめる。 主昼食の決定店。12:00-16:00、L.O. 15:30。リムジンバス乗車後、到着見込みで予約または当日入店を判断する。

店選びはこの順番

  1. 12時以降に「串カツ しろたや 道頓堀本店」で主昼食。
  2. 列が短ければ「わなか」でたこ焼きを一皿。
  3. 「たこ八」または「千房」で、お好み焼き系を一皿だけ分ける。
  4. 551蓬莱の列が短く、まだ食べられそうなら豚まんを一個だけ分ける。

制覇は完食競争ではなく、三人で代表的な味を知ること。各店で注文を増やしすぎず、 たこ焼き、お好み焼き系、551蓬莱の豚まんは、待ち時間が長ければ飛ばす。営業時間は旅行直前と店頭の案内を優先する。

通天閣オプション

14:15時点で全員が元気、暑さ指数が28未満、待ち15分以内の見込みなら、 日本橋駅から通天閣へ直接向かう。新世界散策や追加の食事はせず、15:30頃にはホテルへ向かう。 一つでも条件を満たさなければ、道頓堀からそのままホテルへ戻る。

削る順番

  1. 追加の食べ比べや写真スポット。
  2. 通天閣。道頓堀からそのままホテルへ戻る。
  3. しろたやの串カツを少ない本数にし、ホテルへ戻る。
